# Content Structure

## Site Map
- `/` Home
- `/work` All projects
- `/work/[slug]` Project detail
- `/about` About Yehonatan
- `/contact` Contact and collaboration form

## Project Model
Each project should include:
- `slug`
- `title`
- `category`
- `summary`
- `services` (array)
- `heroImage`
- `year`
- `challenge`
- `process`
- `outcome`

## Default Project Slugs (v1)
- `logo-design`
- `packaging-design`
- `experimental-typography`
- `web-design`
- `thoughtful-design`
- `identity`

## Home Page Content Blocks
- Hero statement and CTA
- Selected work preview cards
- Short about teaser
- Contact CTA

## Work Index
- Grid/list of all six projects
- Category and summary visible per card
- Touch-friendly cards with clear click target

## Project Detail Template
1. Hero section (title, category, summary)
2. Role/services and project meta
3. Challenge
4. Process
5. Outcome
6. Back-to-work navigation and contact CTA

## Contact Content
- Brief invitation for collaboration
- Form fields: name, email, message
- Submission to Formspree endpoint

## Asset Guidelines
- Keep image naming clear and URL-safe
- Prefer consistent dimensions per content type
- Use placeholders until final assets are available
