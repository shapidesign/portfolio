# Project Brief

## Project Name
Simple Portfolio - Yehonatan Shapira

## Vision
Create a clean, memorable, and professional portfolio website for a visual creator. The site should feel modern, geometric, and calm, with clear hierarchy and lightweight motion.

## Audience
- Potential clients
- Creative collaborators
- Studios and agencies

## Brand Positioning
Yehonatan Shapira is a visual creator focused on thoughtful and expressive design outcomes across identity, digital, and experimental work.

## Core UX Goals
- Fast understanding of who Yehonatan is and what he does.
- Easy browsing of projects on desktop and mobile.
- Smooth path to contact and collaboration.

## Content Scope (v1)
- Hero and navigation
- Work index
- 6 project categories:
  1. Logo design
  2. Packaging design
  3. Experimental typography
  4. Web design
  5. Thoughtful design
  6. Identity
- About page
- Contact page with working form
- Downloadable CV link

## Technical Direction
- Next.js app router
- Geometric visual motif with tokenized color system
- Formspree integration for contact form submission

## Success Criteria
- Clear storytelling and professional presentation
- Responsive and touch-friendly behavior
- Accessibility basics and reduced-motion support
- Contact form submissions successfully delivered to configured inbox
