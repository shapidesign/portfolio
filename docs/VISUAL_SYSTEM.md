# Visual System

## Direction
The design language is geometric, minimal, and high-contrast without feeling heavy. Layouts remain simple, with accent motion and strong whitespace.

## Color Palette Strategy
- **Primary:** Deep indigo/navy for text anchors and strong UI moments
- **Secondary:** Soft violet/purple for backgrounds and supporting surfaces
- **Accents:** Warm yellow, cyan, and pink used in controlled doses

Use color with intent:
- Primary for structure and hierarchy
- Secondary for atmosphere
- Accents for calls to action and geometric highlights

## Geometric Motifs
- Circle
- Quarter-circle arc
- Rectangular block
- Dot cluster

Rules:
- Keep motifs decorative and non-blocking.
- Avoid visual overlap with body text.
- Repeat motifs consistently for brand recognition.

## Typography
- Sans-serif family with strong legibility
- High contrast in heading scale
- Compact paragraph width for easy reading

## Layout and Spacing
- Mobile-first spacing system
- Consistent horizontal rhythm across sections
- Clear section separation through whitespace, not excessive borders

## Motion
- Short transitions (about 160-320ms)
- Transform and opacity preferred over layout-changing animations
- Reduced-motion variant required

## Component Philosophy
- Reusable cards, sections, and decorative primitives
- Stable content containers with optional accent layers
- Buttons and links with clear interactive states
